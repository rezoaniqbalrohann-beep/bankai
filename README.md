## ✨ Features & Highlights
1. **Modern Aesthetic & UI:**
   - Dark mode & Light mode theme switcher with local storage persistence.
   - Ambient background glow effects and glassmorphism cards.
   - Gradient typography and smooth transitions.
2. **Interactive Elements:**
   - Dynamic typewriter effect cycling through your roles and interests.
   - Animated skill progress bars on scroll.
   - Mobile navigation drawer with hamburger animation.
   - One-click copy buttons for email and phone number with toast notifications.
   - Interactive contact form with client-side validation and feedback notifications.
   - Floating "Back to Top" button.
3. **Structured Sections:**
   - **Hero Section:** Introduction, quick contact pills, and visual tech profile badge.
   - **About Section:** Detailed bio, career highlights, and personal details card.
   - **Skills Section:** Breakdown of Web Development, Web Design, Graphics, Illustration, Basic Computing, and Programming.
   - **Projects Section:** Showcase cards for featured works.
   - **Contact Section:** Direct contact info cards, social links, and message form.
